# The History of Pixel-Network

This repository is the very first repository of our former organization, **Pixel-Network**.

Rather than deleting it, we have decided to archive it to preserve a piece of our history. We invested a great deal of time, effort, and passion into developing this PHP code back then, and we believe that some things are worth keeping around for nostalgia's sake.

As part of preserving this project, we will also change the repository's visibility to **Public**, allowing others to explore the code and see a small part of our journey.

Our current project is **[VioServe](https://vioserve.de)**.

*Some projects deserve to be remembered.*

# Die Geschichte von Pixel-Network

Dieses Repository ist das allererste Repository unserer früheren Organisation **Pixel-Network**.

Anstatt es zu löschen, haben wir uns dazu entschieden, es zu archivieren, um ein Stück unserer Geschichte zu bewahren. Damals haben wir viel Zeit, Mühe und Leidenschaft in die Entwicklung dieses PHP-Codes gesteckt, und wir glauben, dass manche Dinge es wert sind, aus nostalgischen Gründen erhalten zu bleiben.

Um dieses Projekt zu bewahren, werden wir außerdem die Sichtbarkeit des Repositorys auf **Public** ändern, sodass andere den Code erkunden und einen kleinen Einblick in unsere Reise erhalten können.

Unser aktuelles Projekt ist **[VioServe](https://vioserve.de)**.

*Manche Projekte verdienen es, in Erinnerung zu bleiben.*
